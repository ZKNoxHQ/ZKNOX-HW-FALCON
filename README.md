## What this delivers

- **Parametrized build** through `FALCON_VARIANT={512,1024}` in the Makefile (default 1024 — backward compatible).
- **Same architecture** as v0.7.0: streamed encrypted+MAC'd LDL tree from host. Same `cx_outsourced` module, unchanged. Same APDU spec.
- **Reference testvec** generated by `tools/wire_sim.c`, validated byte-for-byte against the v0.7.0 Falcon-1024 reference (matches `855edeed...` from same simulator with `FALCON_VARIANT=1024`).
- **Domain-separated keys**: `"Falcon-512 seed"` modifier in SLIP-10 derivation produces a different key than Falcon-1024 from the same mnemonic. Intentional.

## Sizes

| Quantity                     | Falcon-1024 | Falcon-512 |
|------------------------------|------------:|-----------:|
| FLOGN                        | 10          | 9          |
| FN                           | 1024        | 512        |
| Wire                         | 122,864 B   | **57,328 B**|
| Public key (raw uint16[N])   | 2,048 B     | 1,024 B    |
| Signature max                | 2,420 B     | 690 B      |
| BSS work area                | 32,768 B    | 16,384 B   |

## Reproducing the testvec

```bash
# Step 1 — write the seed
python3 -c "
import hmac, hashlib
from mnemonic import Mnemonic
mnemo = Mnemonic('english')
bip39 = mnemo.to_seed(('yellow ' * 12).strip())
def slip10_master(s, m):
    h = hmac.new(m, s, hashlib.sha512).digest()
    return h[:32], h[32:]
def slip10_child(k, c, i):
    h = hmac.new(c, b'\x00' + k + i.to_bytes(4,'big'), hashlib.sha512).digest()
    return h[:32], h[32:]
k, c = slip10_master(bip39, b'Falcon-512 seed')
for L in [44, 9004, 0, 0, 0]:
    k, c = slip10_child(k, c, L | 0x80000000)
open('/tmp/falcon_seed.bin','wb').write(k)
print(k.hex())
"

# Step 2 — build and run the simulator (against Falcon's reference impl)
gcc -O2 -DFALCON_VARIANT=512 -DTARGET_AVX2= -I /path/to/falcon-reference \
    tools/wire_sim.c \
    /path/to/falcon-reference/{sign,keygen,codec,common,falcon,fft,fpr,rng,shake,vrfy}.c \
    -o /tmp/wire_sim_512 -lm
/tmp/wire_sim_512

# Step 3 — verify outputs
sha256sum /tmp/falcon_h_raw.bin /tmp/falcon_wire.bin
```
